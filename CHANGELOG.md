# Changelog

## [2.0.0] — 2026-03-28

### Добавлено
- **Пакетная структура** — проект реорганизован в пакет `keycloak_userator/` с модулями:
  - `cli.py` — точка входа, argparse
  - `config.py` — конфигурация, валидация
  - `types.py` — TypedDict структуры
  - `password.py` — генератор паролей
  - `exporter.py` — экспорт в CSV/TXT/JSON
  - `keycloak_client.py` — Keycloak API клиент
- **Тестирование** — 145 тестов (pytest), покрытие 93%+
- **.env поддержка** — автоматическая загрузка через `load_dotenv()`
- **Инструменты качества** — ruff (линтинг), mypy (типы), bandit (безопасность)
- **Документация** — обновлены README.md, QWEN.md

### Изменено
- **Entry point** — `python -m keycloak_userator.cli` (рекомендуется)
- **Старый скрипт** — `keycloak_user_generator.py` сохранён как обёртка для обратной совместимости

### Исправлено
- **.env загрузка** — добавлен вызов `load_dotenv()` в `main()`
