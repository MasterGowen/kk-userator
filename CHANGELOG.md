## [2.1.0] — 2026-03-28

### Добавлено
- **Чистая архитектура** — разделение на слои (протоколы → реализации → сервисы):
  - `protocols.py` — протоколы (интерфейсы) компонентов
  - `providers.py` — реализации провайдеров (`ConcreteKeycloakProvider`)
  - `services.py` — сервисный слой с бизнес-логикой (`UserService`)
  - `exceptions.py` — иерархия исключений
- **Dependency Injection** — внедрение зависимостей через конструкторы
- **src/ структура** — стандартная структура Python-пакета (PEP 517)
- **Типизация** — полная типизация (mypy --strict: 0 ошибок)
- **LICENSE** — MIT License
- **docs/README.md** — навигация по документации
- **.env.example** — полный шаблон со всеми переменными

### Изменено
- **CLI интерфейс** — `--interactive` вместо `--no-interactive` (стандарт для CLI)
- **Обработка ошибок** — улучшена с использованием иерархии исключений
- **Документация** — обновлены README, QWEN, оператор-гайд

### Удалено
- **requirements.txt** — дублирование pyproject.toml
- **audit-файлы из пакета** — `deviation-audit-*.md`, `audit-review-*.md` (внутренняя кухня)

### Исправлено
- **mypy предупреждения** — 0 ошибок в strict режиме
- **ruff предупреждения** — все исправления применены

## [2.0.0] — 2026-03-28

### Добавлено
- **Пакетная структура** — проект реорганизован в пакет `keycloak_userator/` с модулями:
  - `cli.py` — точка входа, argparse
  - `config.py` — конфигурация, валидация
  - `types.py` — TypedDict структуры
  - `password.py` — генератор паролей
  - `exporter.py` — экспорт в CSV/TXT/JSON
  - `keycloak_client.py` — Keycloak API клиент
- **Тестирование** — 145 тестов (pytest), покрытие 93%+
- **.env поддержка** — автоматическая загрузка через `load_dotenv()`
- **Инструменты качества** — ruff (линтинг), mypy (типы), bandit (безопасность)
- **Документация** — обновлены README.md, QWEN.md

### Изменено
- **Entry point** — `python -m keycloak_userator.cli` (рекомендуется)
- **Старый скрипт** — `keycloak_user_generator.py` сохранён как обёртка для обратной совместимости

### Исправлено
- **.env загрузка** — добавлен вызов `load_dotenv()` в `main()`
