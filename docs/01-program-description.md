# Описание программы Keycloak User Generator

## 1. Общие сведения

**Наименование:** Keycloak User Generator (kk-userator)

**Версия:** 2.0.0

**Назначение:** Массовое создание учётных записей пользователей в системе управления доступом Keycloak через Admin API.

**Область применения:** 
- Образовательные проекты с массовым созданием учётных записей
- Диссертационные исследования, требующие контролируемой выборки пользователей
- Тестирование интеграции Keycloak с другими системами (OpenEDX, Moodle, etc.)

**Разработчик:** kk-userator project

**Год создания:** 2026

---

## 2. Функциональное назначение

### 2.1. Основные функции

1. **Массовое создание пользователей**
   - Создание от 1 до N пользователей за один запуск
   - Последовательная нумерация логинов (например, `enginc_1`, `enginc_2`, ... `enginc_200`)
   - Автоматическая генерация уникальных паролей

2. **Генерация учётных данных**
   - Логин по шаблону: `{prefix}_{number}`
   - Пароль: случайная строка заданной длины (латиница + цифры)
   - Email: `{prefix}_{number}@{domain}`
   - Имя/Фамилия: по шаблону из конфигурации

3. **Экспорт данных**
   - CSV формат (машиночитаемый)
   - TXT формат (человекочитаемый)
   - JSON формат (для программной обработки)

4. **Управление группами**
   - Автоматическое создание группы для всех пользователей
   - Добавление созданных пользователей в группу

5. **Идемпотентность**
   - Проверка на существование пользователя перед созданием
   - Пропуск существующих пользователей без ошибок
   - Повторный запуск не создаёт дубликаты

6. **Безопасный режим (dry-run)**
   - Проверка конфигурации без реального создания
   - Логирование планируемых действий

### 2.2. Ограничения

- Требуется доступ к Keycloak Admin API
- Необходима учётная запись администратора с правами на создание пользователей
- Максимальное количество пользователей ограничено только временем выполнения

## 3. Архитектура программы

### 3.1. Структура пакета

```
keycloak_userator/
├── __init__.py              # Инициализация пакета, экспорт классов
├── cli.py                   # Точка входа, парсинг аргументов
├── config.py                # Загрузка конфигурации, валидация
├── types.py                 # Типизированные структуры данных
├── password.py              # Генератор паролей
├── exporter.py              # Экспорт в CSV/TXT/JSON
└── keycloak_client.py       # Клиент Keycloak API
```

### 3.2. Компоненты

#### 3.2.1. `cli.py` — Точка входа

**Назначение:** Обработка командной строки, оркестрация компонентов.

**Функции:**
- Парсинг аргументов командной строки
- Загрузка переменных окружения (.env)
- Инициализация компонентов
- Запуск генерации пользователей

#### 3.2.2. `config.py` — Конфигурация

**Назначение:** Загрузка и валидация конфигурации.

**Функции:**
- Загрузка YAML-конфигурации
- Валидация параметров (префикс, домен, длина пароля)
- Перекрытие из переменных окружения
- Перекрытие из аргументов командной строки

**Классы:**
- `Config` — корневой объект конфигурации
- `UserConfig` — параметры пользователей
- `PasswordConfig` — параметры паролей
- `DefaultsConfig` — параметры по умолчанию
- `LoggingConfig` — параметры логирования
- `ConfigLoader` — загрузчик конфигурации

#### 3.2.3. `types.py` — Типы данных

**Назначение:** Типизированные структуры для обмена данными.

**Классы:**
- `UserData` — данные пользователя для создания
- `UserCredentials` — учётные данные (с паролем)
- `ConnectionConfig` — параметры подключения к Keycloak
- `GenerationStats` — статистика генерации

#### 3.2.4. `password.py` — Генератор паролей

**Назначение:** Генерация криптографически стойких паролей.

**Класс:** `PasswordGenerator`

**Методы:**
- `generate()` — генерация одного пароля
- `generate_batch(count)` — генерация пакета паролей

**Алгоритм:**
- Использует `secrets` для криптографической стойкости
- Символы: латиница (a-z, A-Z) + цифры (0-9)
- Длина: настраиваемая (по умолчанию 8)

#### 3.2.5. `exporter.py` — Экспортёр данных

**Назначение:** Сохранение учётных данных в файлы.

**Класс:** `CredentialExporter`

**Методы:**
- `export_csv(users, filename)` — экспорт в CSV
- `export_txt(users, filename)` — экспорт в TXT
- `export_json(users, filename)` — экспорт в JSON

**Форматы:**
- **CSV:** `username,password,email,firstName,lastName,enabled`
- **TXT:** Человекочитаемый формат с разделителями
- **JSON:** Массив объектов с метаданными

#### 3.2.6. `keycloak_client.py` — Клиент Keycloak

**Назначение:** Взаимодействие с Keycloak Admin API.

**Класс:** `KeycloakUserGenerator`

**Методы:**
- `connect()` — подключение к Keycloak
- `_get_or_create_group(name)` — получение/создание группы
- `_user_exists(username)` — проверка существования пользователя
- `_create_user(...)` — создание одного пользователя
- `generate_users(count, start_number)` — генерация пользователей

**Зависимости:**
- `python-keycloak` — официальная библиотека Keycloak Admin API

## 5. Конфигурация

### 5.1. Файл config.yaml

```yaml
# Параметры пользователей
user:
  login_prefix: "enginc"           # Префикс для логинов
  email_domain: "urfu.online"      # Домен для email
  first_name: "Студент"            # Имя по умолчанию
  last_name_template: "Студентов {number}"  # Шаблон фамилии
  group_name: "engforinclusb-users"  # Группа в Keycloak
  default_realm: "master"          # Realm по умолчанию

# Параметры генерации паролей
password:
  length: 8                        # Длина пароля
  use_lowercase: true              # Строчные буквы
  use_uppercase: true              # Заглавные буквы
  use_digits: true                 # Цифры
  use_special: false               # Спецсимволы

# Параметры по умолчанию
defaults:
  count: 200                       # Количество пользователей
  start_number: 1                  # Начальный номер
  output_dir: "output"             # Директория для файлов

# Логирование
logging:
  file: "keycloak_generator.log"
  level: "INFO"
  format: "%(asctime)s - %(levelname)s - %(message)s"
  date_format: "%Y-%m-%d %H:%M:%S"
```

### 5.2. Переменные окружения

| Переменная | Описание | Пример |
|------------|----------|--------|
| `KEYCLOAK_URL` | URL сервера Keycloak | `https://keycloak.urfu.online` |
| `KEYCLOAK_USERNAME` | Логин администратора | `admin` |
| `KEYCLOAK_PASSWORD` | Пароль администратора | `secret` |
| `KEYCLOAK_REALM` | Имя realm | `master` |
| `KEYCLOAK_CONFIG` | Путь к config.yaml | `config.yaml` |
| `KEYCLOAK_LOGIN_PREFIX` | Префикс для логинов | `enginc` |
| `KEYCLOAK_EMAIL_DOMAIN` | Домен для email | `urfu.online` |
| `KEYCLOAK_COUNT` | Количество пользователей | `200` |
| `KEYCLOAK_OUTPUT_DIR` | Директория для файлов | `output` |

### 5.3. Приоритет конфигурации

1. **Аргументы командной строки** (наивысший приоритет)
2. **Переменные окружения**
3. **Файл config.yaml**
4. **Встроенные значения по умолчанию** (низший приоритет)

## 6. Форматы данных

### 6.1. Входные данные

- YAML файл (`config.yaml`)

## 7. Обработка ошибок

### 7.1. Типы ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `KeycloakError: 401 Unauthorized` | Неверные учётные данные | Проверить логин/пароль |
| `KeycloakError: 403 Forbidden` | Недостаточно прав | Требуется роль `realm-management` |
| `ConnectionError` | Keycloak недоступен | Проверить сетевое подключение |
| `ValidationError` | Ошибка валидации конфигурации | Проверить config.yaml |
| `ImportError: python-keycloak` | Не установлены зависимости | `pip install -e .` |

### 7.2. Стратегии обработки

1. **Повторные попытки** — для временных ошибок сети
2. **Пропуск пользователя** — при ошибке создания (не прерывает пакет)
3. **Логирование** — все ошибки записываются в лог
4. **Статистика** — подсчёт успешных/неуспешных операций
