## 🚀 Быстрый старт

### Установка

```bash
# Клонирование репозитория
git clone https://github.com/mastergowen/kk-userator.git
cd kk-userator

# Установка зависимостей
pip install -e .

# Настройка окружения
cp .env.example .env
# Отредактируйте .env, указав ваши данные Keycloak
```

### Использование

```bash
# Неинтерактивный режим (переменные окружения)
python -m keycloak_userator.cli

# Интерактивный режим (запрос данных)
python -m keycloak_userator.cli --interactive

# С указанием параметров
python -m keycloak_userator.cli --count 50 --dry-run
```
