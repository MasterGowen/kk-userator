# ⚠️ Anthropomorphic Debt — Антропоморфный долг

**Принцип:**
> **Сохранять термины-ярлыки** (Координатор, Аналитик, Инженер) — это индексы, ускоряющие навигацию.
> **Удалять термины-свойства** (понимание, фокусировка, эмоции) — это шум, создающий ложную модель.

**Критерий антропоморфизма:**

| Не антропоморфизм (оставить) | Антропоморфизм (удалить) |
|------------------------------|--------------------------|
| Названия ролей (Координатор, Аналитик) | Когнитивные функции (понимание, осознание) |
| Названия паттернов (Супервизор, Рой) | Воля/намерение (выбирает, решает, хочет) |
| Функциональные ярлыки (Компилятор) | Эмоции (фрустрация, токсичность, похвала) |
| Устоявшиеся термины (Pull Request) | Социальные концепции (команда, общение) |

## Правила валидации

**Антропоморфизм (ложь):**
- Приписывает когнитивные функции (понимание, осознание, фокусировка, обучение)
- Приписывает волю/намерение (выбирает, решает, хочет, предпочитает)
- Приписывает эмоции (фрустрация, токсичность, похвала, удовлетворённость)
- Приписывает социальные отношения (команда, общение, менторство)
- Использует моральные императивы (должен, обязан, будь вежлив)
- Предполагает субъективное время (в течение 24 часов)

**Не антропоморфизм (истина):**
- Названия ролей/модулей (Координатор, Аналитик, Инженер, Ревьюер)
- Названия паттернов (Супервизор, Рой, Handoff)
- Функциональные описания (Обработка входа, Маршрутизация)
- Устоявшиеся технические термины (Pull Request, Commit)

## Задача

Проверь каждую запись:
1. Это термин-ярлык (индекс) или термин-свойство (шум)?
2. Верно ли определён антропоморфизм?
3. Корректна ли замена?

## 📋 Определение

**Антропоморфный долг** — использование человеческих концепций для описания машинной системы.

**Почему проблема:**
- Создаёт ложную модель ментального состояния
- Предполагает волю/агентность там, где её нет
- Усложняет понимание реальной работы системы
